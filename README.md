# Homomuse Owner

Momo（Homomuse Owner 节点）——把你自己的电脑变成家人的加密相册服务器。

## 它是什么

- 照片和视频**端到端加密**后才离开你的设备：密钥只在分享者和查看者手里，服务器看不到内容，也解不开。
- 数据**存在你自己的电脑上**（Owner 节点），不在我们的机房；平台只维持极薄的登录、寻址与转发服务。
- 家人凭链接即可查看，无需注册节点；发到谁，谁才能看。

## 安装

- **macOS**：打开 DMG，把 Homomuse Owner 拖入 Applications。首次运行如被 Gatekeeper 拦截，右键 → 打开即可（本应用已完成 Apple 公证，正常情况下双击直达）。
- **Windows**：运行安装程序。安装包未做代码签名，首次运行时 SmartScreen 会提示「Windows 已保护你的电脑」——点「更多信息」→「仍要运行」继续。

## 信任与审计

- 加密在客户端完成，密钥不离开分享者与查看者的设备。
- 《用户协议》与《隐私政策》：<https://app.homomuse.artistfeynman.cn/v2/agreement.html> · <https://app.homomuse.artistfeynman.cn/v2/privacy.html>
- 协议要点：你的内容在你的设备上加密，我们看不到也解不开；订阅到期只暂停新建分享，已有的分享在期限内不受影响、不会被删除。

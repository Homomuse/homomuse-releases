# Homomuse Owner

> **⚠️ Beta 版本**: 当前处于测试阶段，功能可能不稳定，请谨慎用于生产环境。

## 这是什么？

**Homomuse Owner** 是 Homomuse 去中心化数据分发平台的节点管理应用。

- 🔐 **端到端加密** - 所有数据在本地加密，密钥永不离开您的设备
- 📡 **P2P 传输** - 点对点直连，数据不经过中心服务器
- 🗂️ **本地存储** - 数据存储在您自己的设备上，您完全掌控
- 🔗 **IPFS 支持** - 内置 IPFS 节点，内容寻址存储

## 系统要求

- **macOS**: 11.0 (Big Sur) 或更高版本
- **存储空间**: 至少 2GB 可用空间
- **网络**: 需要互联网连接用于初始设置和 P2P 通信

## 安装

1. 下载对应架构的 DMG 文件
2. 双击打开 DMG，将应用拖到 **Applications** 文件夹
3. 首次打开时，系统可能提示"无法验证开发者"，请前往 **系统设置 > 隐私与安全性** 中允许
4. 启动应用，按引导完成初始化

## 自动更新
